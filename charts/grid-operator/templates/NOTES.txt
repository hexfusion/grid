CRD lifecycle:
{{ if .Values.crds.managed }}
  crds.managed is set: the CRDs are templates and upgrade with this release.
  Install with --skip-crds, or Helm also creates them from crds/ and fails.
  helm uninstall keeps them (helm.sh/resource-policy: keep). A rollback
  applies the older schema cluster-wide.
{{ else }}
  Helm installs CRDs from the crds/ directory on initial install, but does
  NOT upgrade or delete them on helm upgrade or helm uninstall. To upgrade
  CRDs from a release artifact:

    helm pull oci://ghcr.io/praxis-proxy/charts/grid-operator --version <version> --untar
    kubectl apply -f grid-operator/crds/

  Or from the repository, pinned to the release commit:

    kubectl apply -k "https://github.com/praxis-proxy/grid/deploy/crds?ref=<commit-sha>"

  From a local checkout:

    kubectl apply -f charts/grid-operator/crds/
{{ end }}
  To remove CRDs (this deletes ALL custom resources of those types):

    kubectl delete crd agenttoolproviders.grid.praxis-proxy.io
    kubectl delete crd gridnetworks.grid.praxis-proxy.io
    kubectl delete crd gridsites.grid.praxis-proxy.io
    kubectl delete crd inferenceproviders.grid.praxis-proxy.io
